# Dad Joke Showdown

My entry for the Dad Joke Showdown on make.fun: "My daughter asked why the moon keeps changing shape. I said, 'It's just going through phases, like you.'" The joke works on a double meaning — the moon literally goes through phases, and teenagers go through phases too, so the dad's answer lands as a gentle tease. `main.py` writes the joke verbatim to `entry.txt` (stdlib only, no network), with guard asserts and a read-back check to make sure the output is exactly the joke, one line, no trailing newline.
